Everything PowerAim does.

A walk through the app: aiming, triggers, anti-recoil, OCR, gamepad support, AutoPlay with a local LLM and the overlays. Each section links to its full guide.

// Keybinds

Almost everything in PowerAim can go on a key.

Any binding can be a combination of keyboard, mouse and gamepad buttons, for example Ctrl + Q + Gamepad LT. You can bind a toggle, an aim, trigger or mapping profile, a custom tool or a whole config. Put these together and one key sets up everything you use in a particular game.

  • Combinations on any device: hold the keys and let go to record them. The bind only fires while every part is held.
  • Toggle anything: every toggle, profile and tool has its own hotkey chip. Click it and press the key or combination you want.
  • Workflows: one key combination can load a config, and that config brings its own tools, triggers and profiles with it.

// 01 · Aiming

Aim & tracking

A YOLOv8 model finds targets in every frame, and your aim profile decides how the mouse moves toward them. Movement is calibrated to your real sensitivity, so a profile feels the same in every game.

  • Several profiles at once: all aim settings live on a profile. More than one can be active, each with its own aim key and an optional OCR condition.
  • Calibrated movement: by default it picks the nearest target and moves in proportion to the distance. The step size comes from the measured screen pixels per mouse count, so it doesn't depend on the game.
  • Choice of smoothing: None, EMA, or an adaptive 1€ filter that stays calm on slow targets and still reacts quickly on flicks.
  • Optional tracking & prediction: per profile you can turn on SORT-style tracking, frame coasting (keeps following a target for a few frames when a detection drops out), switch hysteresis and lead/prediction.
  • Aim region & random point: draw the part of the target to aim at, for example the head. It can also pick a random point inside that area.

// 02 · Trigger bot

Conditional triggers

A trigger clicks, or presses any key sequence you set, as soon as a target is under the crosshair. You decide under which conditions it may fire.

  • Head-area check: it only fires when the crosshair is inside an area you draw on the detected body.
  • OCR conditions: combine values read from the HUD with AND/OR, for example (ammo > 5 OR mag = full) AND weapon contains "AK".
  • Multiple triggers, each with its own keys, key sequences, delays, cooldowns and the programs it applies to.
Open the trigger guide
// 03 · Recoil

Anti-recoil profiles

Anti-recoil pulls your aim back down while you spray. A profile turns on with a hotkey, or switches automatically based on the weapon you're holding.

  • Recorded patterns: record a weapon's actual recoil and play it back. Patterns can loop for long sprays.
  • Image-based compensation: compares frames (phase correlation) to see how far the view kicked, and pulls it back down.
  • Activation per profile: bind a key, or let OCR read the weapon name and switch the profile for you.
Open the anti-recoil guide
// 04 · Vision

OCR HUD reader

PowerAim can read numbers and text from your HUD, such as ammo, health or the weapon name, and other features can react to them.

  • Region types: mark an area as Number, Health or Text. Color-aware preprocessing helps with stylized or colored HUD fonts.
  • Used across the app: block a trigger, pause aim while the knife is out or you aren't scoped in, or switch aim and recoil profiles automatically.
  • Condition trees built with the same AND/OR editor as the triggers.
Open the OCR guide
// 05 · Controllers

Gamepad aim & mapping

Controller support works both ways. You can play controller games with a mouse, or keyboard-only games with a controller.

  • Aim through a virtual stick: PowerAim can send its aim to a virtual Xbox controller created with ViGEm.
  • Mapping in both directions: map a controller to keyboard and mouse or the other way round, with hotkeys per profile, presets and live diagrams of the controller and keyboard.
  • Controller overview: all physical controllers and the virtual one in one list, with slot, sync source and a hide option. One click makes games use the virtual pad.
  • Gamepad tester: a live view of the buttons and sticks of any controller, so you can tell what PowerAim sends apart from your own input.
Open the mapping guide
// 06 · Automation

AutoPlay with a local LLM

An experimental feature. It sends the current game state to a language model running on your PC and lets the model decide what to do.

  • Game state: detections and OCR readings are summarized and passed to a local Ollama model.
  • Profiles & actions: you define which actions it may take, with cooldowns and an action history.
  • Learning mode: records what worked and feeds it back to the model. All of it runs on your machine.
Open the AutoPlay guide
// 07 · Overlays

Crosshair, FOV & ESP overlays

Optional layers drawn over the game. They show what the model detects and help you set the field of view.

  • Crosshair & FOV: a crosshair you can configure and a FOV circle. The circle also sets how much of the screen gets scanned.
  • ESP / detected players: draws detection boxes, confidence values and the trigger head area. Several drawing backends are available.
  • Debug overlay: shows the mouse and stick movements PowerAim generates as they happen.
Open the overlay guide
// 08 · Tools

Dynamic tools

The Tools page is a list of cards you can expand. It holds the built-in Magnifier and HWID spoofer and any tool you build yourself. Each tool has a start key and a start button.

  • Action sequences: chain steps like move mouse, click, send keys, run a program and wait. They run once each time you start the tool.
  • Options as variables: define options with a type and use them in any action field as {name}. You can change them on the card before running.
  • Send keys like triggers: the same multi-key control the triggers use, with sequence recording and Sequential or Simultaneous mode.
  • Hotkey per tool: start a tool by key or button. Pressing it again cancels the run, releases anything it was holding and starts over.
Open the tools guide
